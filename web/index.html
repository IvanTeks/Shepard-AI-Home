GOOGLE CALENDAR SETUP

One-time local OAuth setup

Create a Google OAuth desktop client and start Shepard with GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET. Shepard requests read-only calendar access first.

Redirect URI: http://127.0.0.1:8765/oauth/google-calendar/callback

GEMINI API SETUP

Connect your Google AI Studio key

The key is tested directly with the Gemini API, then stored only in Shepard's ignored local secrets folder. It provides AI models—not Calendar or Gmail access.

OUTLOOK WEB BRIDGE

Share Outlook with Shepard—no Azure setup

New Outlook does not expose your cloud mailbox to local Mac automation. Instead, use your existing signed-in Outlook Web session and explicitly share only the inbox or calendar page you want Shepard to read.

  1. Open Outlook Mail or Outlook Calendar in Chrome and sign in normally.
  2. Open the Shepard Chrome Bridge extension.
  3. Choose Share current page, then ask Shepard about your inbox or calendar.

Only the page you choose is shared. The text stays in Shepard's memory for at most one hour. Passwords, cookies, history, and other tabs are not read.
